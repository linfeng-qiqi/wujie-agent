# 无界 Wujie

> **不用装任何 App——你已经在用的聊天软件，就是它的入口。**
> 一个平台无关的 Agent 内核，以「插件」形式插到 QQ / 企业微信 / 钉钉等任意消息平台上。

「无界」有两层意思：**不受平台限制**（一个内核，多处接入），**不受安装限制**（不用下载客户端，发条消息就能使唤）。

纯 Python 标准库实现、零第三方依赖。查天气、搜资讯、查票价、写东西、读文档、记事情——全部跑在你自己的服务器上，本地模型零成本，联网搜索不依赖任何付费 API。

```
        ┌─────────┬─────────┬─────────┐
        │   QQ    │企业微信 │  钉钉   │   ← 平台适配层（可插拔）
        └────┬────┴────┬────┴────┬────┘
             └─────────┼─────────┘
                       ↓ 统一的消息/事件接口
          分流 → 规则化拆解 → 多 Agent 并行(联网/文档/记忆) → 整理 → 回复
                       ↓
               本地 Ollama / 可选在线模型
```

> 当前已实现 **QQ**（NapCat / OneBot11）适配器，其他平台适配层按同一接口扩展即可。

---

## 为什么不需要装软件

传统 AI 助手要你下载 App、注册账号、把数据交给别人。无界反过来：

- **入口就是你已有的聊天框**——QQ 发消息、以后企微发消息，都是同一个 Agent
- **数据留在你自己的服务器**——任务、记忆、消息都存在本地 SQLite，不上传第三方
- **平台是可换的插件**——换平台不用重写 Agent，只换一层薄薄的适配代码

| 特性              | 说明                                                                  |
| --------------- | ------------------------------------------------------------------- |
| **平台可插拔**      | Agent 内核与消息通道解耦，QQ 已实现，企业微信 / 钉钉等按统一接口接入                          |
| **本地优先，零成本**    | 默认走本地 Ollama（`qwen3:1.7b`），日常问答一分钱不花；可选切换在线模型                       |
| **自家联网搜索**      | 5 源并发（360 / 必应中国 / 搜狗 / 必应国际 / 头条）+ 多轮研究式检索，找不到就换词继续找，不依赖任何付费搜索 API |
| **多 Agent 并行**  | 协调器规则化拆解（毫秒级、零 token），搜索 / 文档 / 记忆 Agent 并行执行                       |
| **上下文串联**       | 追问自动补全（「高铁票呢」能接上上一句的航线），不建多余 Agent                                  |
| **稳定记忆 + 分层缓存** | 记住你说过的稳定事实；搜索结果按事实 30 天 / 新闻 2 小时 / 天气 30 分钟缓存，命中零 token            |
| **全流程可追溯**      | 每个 Agent 的动作实时落库，发 `查看agent列表`、`查看N` 就能看到它在干什么                    |
| **零第三方依赖**      | 只用 Python 标准库，WebSocket、爬虫、SQLite、文档处理全部手写，pip install 都不用          |
| **QQ 适配器**      | 通过 NapCat 的 OneBot11 协议收发消息，扫码登录，稳定可控                               |

## 目录结构

```
wujie-agent/
├── main.py              # 主程序入口（启动 Agent 系统）
├── listener.py          # 独立消息监听器（可选，主程序已内置收消息）
├── paths.py             # 路径与连接配置（全部环境变量可覆盖）
├── config.py            # 配置读写（密钥脱敏、命令解析）
├── db.py                # SQLite 存储层（WAL 模式，读写不阻塞）
├── bus.py               # QQ 平台适配器：NapCat WS 收 / HTTP 发 + 附件处理
├── ai.py                # 模型路由：本地 Ollama / DeepSeek，含联网工具
├── agents.py            # Agent 群：协调器 / 搜索 / 文档 / 整理 / 自愈
├── crawler.py           # 自家爬虫：5 源并发 + 多轮研究式检索
├── memory.py            # 记忆系统：稳定事实 / 情节 / 技能
├── cache.py             # 分层缓存：事实 / 新闻 / 天气 / 票务
├── core.py              # 任务调度、分流、菜单、命令
├── trace.py             # 追溯文档生成
├── config.example.json  # 配置模板（复制为 config.json 后填写）
├── docs/                # 部署与设计文档
├── tests/               # 冒烟测试
└── data/                # 运行时数据（自动生成，已 gitignore）
```

## 快速开始

### 前置条件

- Linux 服务器（推荐 Ubuntu 22.04+，2 核 4G 起步）
- Python 3.10+
- Docker（跑 NapCat，当前 QQ 适配器所需）
- [Ollama](https://ollama.com/)（本地模型，可选但推荐）

### 1. 克隆与配置

```bash
git clone https://github.com/<你的用户名>/wujie-agent.git
cd wujie-agent

# 复制配置模板，按需修改
cp config.example.json config.json
chmod 600 config.json
```

`config.json` 里最关键的是 `target_qq`（你的 QQ 号）和 `bot_qq`（机器人 QQ 号）。密钥可以留空——默认走本地模型，不需要密钥。

### 2. 安装 Ollama 与本地模型

```bash
curl -fsSL https://ollama.com/install.sh | sh
ollama pull qwen3:1.7b
```

> 4 核 4G 的机器建议 `qwen3:1.7b`；性能更好的可以上 `qwen3:4b`。切模型见下方命令。

### 3. 部署 QQ 适配器（NapCat 协议端）

```bash
docker run -d --name napcat \
  -p 3000:3000 -p 3001:3001 -p 6099:6099 \
  -v "$PWD/napcat-data":/home/container \
  mlikiowa/napcat-docker:latest
```

启动后打开 `http://<服务器IP>:6099/webui`，用配置里的 token 登录，完成两件事：

1. **扫码登录机器人 QQ**
2. 在「网络配置 → OneBot11」开启正向 WebSocket，端口 `3001`

配置模板在 `docs/napcat-config-example/`，可直接参考。

### 4. 启动

```bash
python3 main.py
```

看到「QQ AI 助手启动」且 NapCat 已登录，就可以给你的机器人发消息了。

### 5.（可选）用 systemd 托管

见 [`docs/deployment.md`](docs/deployment.md)，包含开机自启、路径配置、多服务协同的完整说明。

## 配置说明

所有路径和连接地址都能用环境变量覆盖，不必改代码：

| 环境变量                | 作用                 | 默认值                 |
| ------------------- | ------------------ | ------------------- |
| `WUJIE_HOME`       | 数据根目录              | 脚本所在目录              |
| `WUJIE_NAPCAT_DIR` | NapCat 数据目录        | `<数据根>/napcat-data` |
| `WUJIE_WS_HOST`    | NapCat 正向 WS 主机    | `127.0.0.1`         |
| `WUJIE_WS_PORT`    | NapCat 正向 WS 端口    | `3001`              |
| `WUJIE_HTTP_PORT`  | NapCat HTTP API 端口 | `3000`              |
| `WUJIE_TARGET_QQ`  | 只处理该 QQ 号的消息       | 空=不过滤               |

`config.json` 主要字段：

| 字段                         | 说明                                    |
| -------------------------- | ------------------------------------- |
| `provider`                 | `local`（本地 Ollama，默认）/ `deepseek`（在线） |
| `model_local`              | 本地模型名，如 `qwen3:1.7b`                  |
| `model_fast` / `model_pro` | 在线快模型 / 强模型                           |
| `api_key` / `base_url`     | 在线模式才需要；本地模式可留空                       |
| `target_qq` / `bot_qq`     | 你的 QQ / 机器人 QQ                        |
| `concurrency`              | 并发 Agent 上限，默认 4                      |

**在线模式切换**：QQ 发 `切换本地` / `切换在线` / `模型状态`；也可以发 `本地模型 qwen3:4b` 换本地模型。

## 命令速查（当前 QQ 适配器）

发 `菜单` 查看全部 13 项，常用：

| 命令              | 作用                       |
| --------------- | ------------------------ |
| `菜单`            | 打开菜单（120 秒内有效，可直接回数字）    |
| `查看agent列表`     | 任务运行中查看 Agent 实时状态       |
| `查看N`           | 看第 N 个 Agent 的动作轨迹       |
| `清空所有任务`        | 清空任务数据（需二次确认，保留记忆/缓存/设置） |
| `切换本地` / `切换在线` | 切换模型供应商                  |
| `模型状态`          | 查看当前模型                   |
| `查看用量` / `查看余额` | token 用量与费用估算            |
| `设置密钥sk-xxxx`   | 配置 DeepSeek 密钥（一行搞定）     |

**普通聊天不建 Agent**：追问、寒暄、常识问答直接带上下文回答；只有查询、搜索、写作、多任务才创建 Agent。

## 接入新平台（插件化扩展）

Agent 内核（`core.py` / `agents.py` / `ai.py` 等）完全不感知消息来自哪个平台。要接企业微信、钉钉或飞书，只需要实现一个**平台适配器**，满足下面这份薄接口：

```python
# 适配器需要提供的最小接口（参考 bus.py 的 QQ 实现）
def listen(on_message):     # 收到消息 → 回调 on_message(text, uid, attachments)
    ...

def send_text(uid, text):   # 把 Agent 的回复发回去
    ...

def send_file(uid, path):   # 发送文件/附件（可选）
    ...
```

步骤：

1. 新建 `adapters/wecom.py`（或 `dingtalk.py`），实现上面三个函数
2. 在 `main.py` 里把 `import bus` 换成对应适配器
3. 其余代码零改动——分流、拆解、联网、记忆、缓存全自动复用

> 当前内置的 QQ 适配器基于 NapCat / OneBot11。欢迎 PR 新平台适配器。

## 设计原则

1. **零依赖**：只用 Python 标准库，降低部署和维护门槛。
2. **本地优先**：数据不出服务器，日常使用零成本；在线模型只是可选增强。
3. **可控可停**：每一步动作可见、可中断，不做黑盒。
4. **省钱**：规则化拆解替代模型拆解（省 token），搜索缓存复用（命中零 token），本地整理替代长正文回灌。
5. **诚实**：查不到就说查不到，不编造；跑题输出会被拦截。

架构细节见 [`docs/agent-design.md`](docs/agent-design.md)。
